# Netflix Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project analyzes the Netflix Movies and TV Shows dataset. The project includes data cleaning and feature engineering using Python and Pandas, exploratory data analysis (EDA), and an interactive dashboard built using Microsoft Power BI.

The goal of this project is to understand Netflix's content library, including content types, ratings, genres, countries, release years, and content trends over time.
